**1.1 - Laptop Hardware**

**Main Idea**

Laptops are compact and portable computers that contain many small hardware components inside a limited space.Because of this compact design, troubleshooting and upgrading laptops can sometimes be difficult and varies between manufacturers.

This video explains:

-   Laptop batteries

-   Keyboards

-   Laptop RAM

-   Storage devices

-   Wireless cards

-   Biometrics

-   NFC

-   Webcams and microphones

⸻

**1\. Laptop Design and Troubleshooting**

Laptops are built with very precise engineering because manufacturers try to fit powerful hardware into a very small device.

**Important Point**

Not all laptops are equally repairable.

Some laptops:

-   Allow easy access to RAM and storage

-   Have removable batteries

-   Are easy to upgrade

Other laptops:

-   Are sealed tightly

-   Have soldered components

-   Are difficult to repair or upgrade

Because of this:

-   Every manufacturer may have different repair procedures

-   You should always follow the manufacturer documentation before opening a laptop

⸻

**2\. Laptop Batteries**

**Types of Laptop Batteries**

Modern laptops mainly use:

**1) Lithium-Ion (Li-ion)**

**2) Lithium-Ion Polymer (LiPo)**

Both:

-   Do NOT suffer from the old “memory effect”

-   Can be recharged anytime safely

-   Maintain battery capacity better than old battery technologies

⸻

**Memory Effect**

Older batteries had a problem called memory effect.

Meaning:

-   If you recharged before fully draining the battery,

-   The battery “remembered” a smaller capacity.

Modern lithium batteries do not have this issue.

⸻

**3\. Modular vs Non-Modular Batteries**

**Modular Battery**

A removable battery.

Features:

-   Easy to remove and replace

-   User can swap it quickly

-   Usually has a release button or latch

**Advantage**

Easy maintenance and replacement.

⸻

**Non-Modular Battery**

Built inside the laptop.

Features:

-   Cannot easily be removed

-   Often requires opening the laptop completely

-   Usually needs a technician

**Important Exam Point**

Modern thin laptops commonly use non-modular batteries.

⸻

**4\. Battery Form Factors**

Each laptop model usually uses a unique battery shape and connector.

That means:

-   You must buy the exact battery for the exact laptop model

-   Batteries from other laptops usually will not fit

⸻

**5\. Laptop Keyboards**

The keyboard is one of the most used laptop components.

Because of constant use:

-   It commonly fails or needs replacement

⸻

**Keyboard Replacement**

Most manufacturers make keyboard replacement relatively easy.

Usually:

-   Remove screws or bezel

-   Keyboard pops out as one unit

-   Disconnect ribbon cable

-   Install new keyboard

⸻

**6\. Ribbon Cable**

Laptop keyboards usually connect using a ribbon cable.

**Ribbon Cable Characteristics**

-   Thin and flat

-   Fragile

-   Connects keyboard to motherboard

You must handle it carefully during replacement.

⸻

**7\. External USB Keyboard for Troubleshooting**

If laptop keyboard has issues:

-   Connect external USB keyboard

This helps determine whether:

-   Problem is hardware relatedOR

-   Operating system related

**Example**

If external keyboard works:→ Internal keyboard hardware may be damaged.

⸻

**8\. Laptop Keyboard Special Keys**

Laptop keyboards are compact.

Because of limited space:

-   Some keys perform multiple functions

Examples:

-   Function key (Fn)

-   Windows key

-   Multimedia shortcuts

Some larger laptops may also include:

-   Numeric keypad

⸻

**9\. Replacing Individual Keys**

Sometimes only one keycap is damaged.

Desktop keys:

-   Easier to replace

Laptop keys:

-   Very delicate and fragile

**Important**

Always follow manufacturer instructions because:

-   Small plastic parts under keycaps break easily

⸻

**10\. Laptop Memory (RAM)**

Desktop RAM is too large for laptops.

Laptops use:

**SO-DIMM**

Small Outline Dual In-line Memory Module

This is a smaller RAM form factor designed for laptops.

⸻

**11\. Modular vs Soldered RAM**

**Modular RAM**

-   Can be removed/upgraded

-   Installed in SO-DIMM slots

**Soldered RAM**

-   Permanently attached to motherboard

-   Cannot be upgraded

-   Requires replacing motherboard to upgrade RAM

**Important Exam Point**

Thin ultrabooks often use soldered RAM.

⸻

**12\. Installing SO-DIMM Memory**

Steps:

1.  Open RAM access panel

2.  Insert RAM at an angle

3.  Push downward

4.  Clips lock RAM into place

⸻

**13\. Laptop Storage Devices**

Laptops store:

-   Operating system files

-   Applications

-   User data

⸻

**14\. HDD (Hard Disk Drive)**

Older laptops commonly used:

**2.5-inch HDD**

Characteristics:

-   Spinning platters

-   Mechanical moving parts

-   Slower

-   Less reliable

**Important**

Desktop drives are usually:

-   3.5-inch

Laptop drives are:

-   2.5-inch

⸻

**15\. SSD (Solid State Drive)**

Modern laptops mostly use:

**SSDs**

Characteristics:

-   No moving parts

-   Faster

-   More reliable

-   Better battery life

-   Faster boot times

⸻

**16\. M.2 SSD**

Modern laptops commonly use:

**M.2 SSD**

Advantages:

-   Much smaller

-   Faster installation

-   Better for thin laptops

⸻

**Difference Between 2.5-inch Drive and M.2**

**2.5-inch Drive**

Needs:

-   Data cable

-   Power cable

**M.2 Drive**

-   Connects directly to motherboard

-   No separate cables

⸻

**17\. Installing an M.2 SSD**

Steps:

1.  Insert M.2 card into slot at angle

2.  Push gently until fully connected

3.  Push downward

4.  Secure with screw

**Important**

No copper contacts should remain visible after insertion.

⸻

**18\. Upgrading HDD to SSD**

One of the best laptop upgrades:Replacing HDD with SSD.

Benefits:

-   Faster system

-   Better performance

-   Higher reliability

Can make old laptop feel new again.

⸻

**19\. Disk Imaging / Cloning**

Instead of reinstalling everything manually:

-   Use imaging/cloning software

This copies:

-   Operating system

-   Applications

-   Files

-   Settings

From old drive to new drive.

⸻

**Imaging vs Cloning**

**Imaging**

Creates image file first.

Process:Old drive → image file → new drive

⸻

**Cloning**

Copies directly from one drive to another in real time.

Process:Old drive → new drive directly

⸻

**20\. Wireless Connectivity**

Modern laptops heavily depend on wireless networking.

Common technologies:

-   Wi-Fi (802.11)

-   Bluetooth

Some newer laptops:

-   No longer include Ethernet ports

⸻

**21\. Wireless Cards**

Older laptops may use:

-   Mini PCI

-   Mini PCIe cards

These provide:

-   Wi-Fi functionality

Characteristics:

-   Modular

-   Replaceable

⸻

**22\. Wireless Antennas**

Wireless cards connect to antennas inside laptop display.

Usually:

-   Main antenna

-   Auxiliary antenna

Bluetooth may use:

-   Third antenna

These antenna wires often run around the screen edges.

⸻

**23\. Installing Wireless Cards**

Steps:

1.  Open laptop panel

2.  Insert wireless card

3.  Lock card into slot

4.  Connect antenna wires

**Important**

Tiny antenna connectors are delicate.
