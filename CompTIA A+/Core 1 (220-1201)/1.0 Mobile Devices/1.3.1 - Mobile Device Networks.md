# 1.3 - Mobile Device Networks


## Main Idea

Mobile devices such as smartphones and tablets use several different technologies to communicate with networks and other devices.

This video focuses on:

-   Cellular networks: 3G, 4G/LTE, LTE-A, and 5G

-   Wi-Fi / 802.11

-   Mobile hotspot

-   SIM and eSIM

-   Bluetooth pairing

-   GPS and other location technologies

The key idea is that **mobile devices can connect to networks in different ways depending on the technology, range, speed, and purpose.**

---

# 1\. Cellular Networks

When we say **cell phone**, the word "cell" comes from **cellular networks**.

A cellular network divides a large geographic area into smaller areas called **cells**.

Each cell is served by one or more antennas/towers that provide wireless coverage.

### How it works

Think of an entire city divided into many areas:

**Cell → Antenna/Tower → Mobile Device**

As you move from one cell to another, your phone can communicate through different cellular antennas while maintaining network connectivity.

Cellular networks provide:

-   **Voice communication**

-   **Data communication**

For example:

-   Phone calls → voice

-   Internet browsing → data

-   Streaming → data

-   Messaging apps → data

---

# 2\. Cellular Data

Modern phones allow you to control whether cellular data is enabled.

For example, you can:

-   Enable cellular data → use the carrier's network for Internet access.

-   Disable cellular data → prevent apps from using cellular data.

You can still potentially use other communication methods, such as Wi-Fi, when cellular data is disabled.

---

# 3\. Airplane Mode

**Airplane Mode** disables the phone's wireless communication functions.

After enabling Airplane Mode, you can usually choose which wireless functions to turn back on.

For example:

**Airplane Mode ON**

↓

Cellular communication disabled

↓

You can manually enable Wi-Fi or Bluetooth if needed.

### Important

Airplane Mode is essentially a quick way to disable wireless communications, while still allowing you to selectively re-enable certain functions.

---

# 4\. 3G

**3G = Third Generation**

3G technology started becoming widely used around **1998**.

Its major improvement was the ability to transmit and receive significantly more data than earlier cellular technologies.

This increased what mobile devices could do.

### 3G enabled/improved services such as:

-   GPS functionality

-   Mobile television

-   Video on demand

-   Video conferencing

-   Other data-intensive services

### Main idea

**3G → More cellular data → More capable mobile devices**

---

# 5\. 4G

After 3G came **4G**.

4G significantly increased cellular data capabilities.

The video associates 4G with technologies such as:

### LTE

**LTE = Long-Term Evolution**

LTE became a major 4G technology.

The video also mentions:

### GSM

**GSM = Global System for Mobile Communications**

GSM is a cellular technology associated with 4G/LTE networks.

You may also encounter:

### EDGE

**EDGE = Enhanced Data rates for GSM Evolution**

---

## 4G Speed

The video gives a bandwidth/throughput figure of up to approximately:

**150 Mbps**

The important idea for A+ is not simply memorizing the number, but understanding the progression:

**3G → 4G → much higher cellular data speeds**

---

# 6\. LTE Advanced (LTE-A)

4G LTE was later improved with:

# LTE Advanced (LTE-A)

LTE-A increased the amount of data that could be transmitted.

The video gives a throughput of up to:

**300 Mbps**

### Remember

**LTE → LTE Advanced → Higher throughput**

---

# 7\. 5G

Modern cellular networks use:

# 5G = Fifth Generation

The video states that 5G was introduced in **2020**.

5G greatly increased cellular bandwidth compared with previous generations.

Depending on the frequencies being used, the video gives different performance figures.

### Higher-frequency 5G

Can support up to approximately:

**10 Gbps**

### Other 5G frequencies

Can provide approximately:

**100–900 Mbps**

So 5G does not always mean that you will get 10 Gbps.

Actual performance depends on factors such as:

-   Frequency

-   Network configuration

-   Coverage

-   Carrier

-   Device capabilities

---

# 8\. Why 5G Matters

Higher bandwidth changes what mobile devices can do.

One example is:

# IoT — Internet of Things

IoT devices can generate and transmit large amounts of data.

With faster cellular networks, these devices can send data more quickly.

This can provide:

-   Faster notifications

-   Faster data transmission

-   Faster data reception

-   More data sent to the cloud

-   More cloud-based processing

### Example

An IoT device can collect information → send it over a 5G network → upload it to the cloud → the cloud processes it → the user receives the result quickly.

---

# 9\. 802.11 / Wi-Fi

Cellular networks aren't the only wireless technology used by mobile devices.

Another major technology is:

# 802.11

802.11 is the family of standards commonly known as:

**Wi-Fi**

Wi-Fi is commonly used:

-   At home

-   In offices

-   In schools

-   In public locations

Unlike cellular networks, Wi-Fi normally provides **local wireless networking**.

---

# 10\. Wi-Fi Access Point

Wi-Fi networks normally use a:

# Access Point (AP)

The mobile device connects wirelessly to the access point.

Example:

**Phone → Wi-Fi Access Point → Network/Internet**

Wi-Fi has a **limited range**, so the device must be within the coverage area of the access point.

---

# 11\. What Can Wi-Fi Carry?

802.11 networks can transmit many types of information, including:

-   Voice

-   Video

-   Data

-   Internet traffic

-   Other network communications

It isn't limited to basic web browsing.

---

# 12\. Wi-Fi Calling

Some mobile phones can make and receive phone calls through a Wi-Fi network.

This is especially useful when cellular coverage is weak.

### Example

You are inside a building.

Cellular signal:

❌ Very weak

Wi-Fi:

✅ Strong

Your phone may be able to use the Wi-Fi network to make and receive calls.

This allows voice communication even when the 4G/5G cellular signal isn't good.

---

# 13\. Mobile Hotspot

A smartphone can act as an **Internet router** for other devices.

This is called:

# Hotspot

The phone connects to the cellular network and shares that Internet connection with other devices.

For example:

**5G cellular network**

↓

**Smartphone**

↓

**Wi-Fi / 802.11**

↓

Laptop + Tablet + Other devices

The phone acts as the middle point between the cellular network and the connected devices.

---

## Hotspot Example

Imagine you're somewhere without Wi-Fi.

Your phone has a 5G connection.

You enable:

**Personal Hotspot**

Your laptop connects to your phone over Wi-Fi.

The laptop can now access the Internet through the phone's 5G connection.

---

# 14\. Hotspot Requires Carrier Support

Hotspot functionality is often built into the phone's operating system.

However, the mobile carrier must allow the feature.

Some carriers:

-   Allow it for free

-   Restrict it

-   Require a specific plan

-   Charge an additional fee

### Exam Concept

**Phone hardware/software supporting hotspot does not necessarily mean the carrier allows it.**

Always check the carrier's plan and policies.

---

# 15\. SIM — Subscriber Identity Module

A mobile carrier needs a way to identify a subscriber and associate that subscriber with a mobile network.

This is where the:

# SIM

comes in.

**SIM = Subscriber Identity Module**

A traditional SIM is a **physical card** inserted into the phone.

It contains information used to identify the subscriber and cellular service.

---

# 16\. What Information Does a SIM Contain?

According to the video, a SIM can contain information related to:

-   Carrier

-   Subscriber/user

-   SIM ID

-   Phone number

-   Cellular network information

The SIM can also provide storage for:

-   Contacts

-   Messages

---

# 17\. Moving a SIM Between Phones

One major advantage of a physical SIM is portability.

You can:

**Phone A**

↓

Remove SIM

↓

Insert SIM into

↓

**Phone B**

This can move the cellular service/number association to the new physical device, assuming the phones/carrier support it.

### Example

You buy a new phone.

Instead of getting a completely new number, you can move your existing physical SIM into the new phone.

Your cellular service can then operate on the new device.

---

# 18\. SIM Storage

The video mentions that a physical SIM may have storage for:

-   Contacts

-   Messages

Therefore, moving the SIM can potentially move those stored contacts/messages as well.

### Important

This is different from modern smartphones, where most contacts and messages are typically stored/synchronized through the phone or cloud services rather than primarily on the SIM.

For the A+ material, remember that **traditional SIM cards can store subscriber/network information and may also store contacts/messages.**

---

# 19\. eSIM

Modern phones may use:

# eSIM

**eSIM = Embedded SIM**

Instead of having a removable physical SIM card, the SIM functionality is embedded into the phone.

### Physical SIM

-   Physical card

-   Can be removed

-   Can be inserted into another compatible phone

### eSIM

-   Embedded inside the device

-   Cannot be physically removed like a traditional SIM

-   Can be transferred/configured using software

---

# 20\. How eSIM Transfer Works

Because an eSIM is embedded in the phone, you can't simply take it out and insert it into another phone.

Instead, the phone provides software options for transferring or adding an eSIM.

For example, you may:

-   Transfer an existing eSIM

-   Add an eSIM

-   Use a **QR code** provided by the carrier

### Basic idea

**Physical SIM:**

Remove card → insert card into another phone

**eSIM:**

Use software → transfer/configure the cellular profile

---

# 21\. Multiple SIMs

Some phones support multiple SIMs simultaneously.

This can allow:

-   Multiple phone numbers

-   Multiple cellular profiles

-   Multiple lines on one phone

Depending on the phone, this can involve:

-   Multiple physical SIMs

-   Physical SIM + eSIM

-   Multiple eSIM profiles

---

# 22\. Physical SIM Size

Traditional SIM cards are very small.

Because of their small size, a special tool is often required to:

-   Open the SIM tray

-   Remove the SIM

-   Insert the SIM

---

# 23\. Bluetooth Pairing

Bluetooth devices such as:

-   Headsets

-   Speakers

-   Keyboards

-   Mice

need to be **paired** with the phone/computer before they can communicate properly.

# Pairing

Pairing is the process of establishing a relationship between two Bluetooth devices.

---

## Why Bluetooth Pairing Is Important

Pairing provides:

1.  A security/verification step

2.  A way for the devices to recognize each other

3.  The ability to reconnect automatically later

Normally, you don't have to repeat the entire pairing process every time you use the device.

---

# 24\. Bluetooth PIN

During the initial pairing process, a:

# PIN — Personal Identification Number

may be used to verify the connection.

The PIN can be:

-   Fixed/embedded in the Bluetooth device

-   Dynamic and different each time

The exact process depends on the Bluetooth device.

### Important

Always check the manufacturer's documentation if you need to know:

-   The correct PIN

-   How to enter it

-   How to put the device into pairing mode

---

# 25\. Bluetooth Pairing Process

The general process is:

### Step 1 — Enable Bluetooth

Turn on Bluetooth on both devices.

Example:

**Phone → Bluetooth ON**

**Headset → Bluetooth ON**

---

### Step 2 — Make the Device Discoverable

The Bluetooth device must be placed into:

**Discoverable / Pairing Mode**

Some devices require:

-   Pressing a button

-   Holding a button

-   Using a specific key combination

-   Following a startup procedure

The exact method depends on the device.

---

### Step 3 — Find the Device

The phone/computer scans for nearby discoverable Bluetooth devices.

The device appears in the Bluetooth device list.

---

### Step 4 — Select the Device

Select the Bluetooth device you want to connect to.

---

### Step 5 — Verify the PIN

The pairing process may ask you to:

-   Confirm a PIN

-   Enter a PIN

The PIN may be printed/provided with the device or generated dynamically.

---

### Step 6 — Pairing Complete

Once verification succeeds:

**Phone ↔ Bluetooth Device**

The devices can communicate.

---

# 26\. Testing Bluetooth Pairing

After pairing, you can test whether the connection works correctly.

One simple test mentioned in the video:

1.  Power off one device.

2.  Power it back on.

3.  Check whether it automatically reconnects.

If it reconnects automatically, the previous pairing information was successfully retained.

---

# 27\. Bluetooth Pairing vs Connecting

This is an important distinction.

### Pairing

The **initial setup/relationship** between two Bluetooth devices.

Usually done once.

### Connecting

Using that already-paired relationship to establish communication.

You can disconnect and reconnect without necessarily repeating the pairing process.

Think:

**Pair once → Connect many times**

---

# 28\. GPS

Another major mobile technology is:

# GPS — Global Positioning System

GPS allows a device to determine its geographic location.

It is commonly used by:

-   Maps

-   Navigation apps

-   Location-based applications

---

# 29\. Who Created GPS?

The GPS system was created by the:

**United States Department of Defense**

It uses satellites orbiting Earth.

---

# 30\. How GPS Determines Location

GPS uses signals from multiple satellites.

The phone receives signals from the satellites and compares differences in those signals to determine its position.

The video states that receiving signals from **four satellites** provides accurate GPS readings.

The system can determine:

-   **Latitude**

-   **Longitude**

-   **Altitude**

---

# 31\. Latitude

**Latitude** tells you how far north or south you are from the equator.

Think:

**North ↕ South**

---

# 32\. Longitude

**Longitude** tells you how far east or west you are.

Think:

**East ↔ West**

---

# 33\. Altitude

**Altitude** represents your height above sea level.

So GPS can provide three-dimensional positioning information:

**Latitude + Longitude + Altitude**

---

# 34\. GPS Is Not the Only Location Technology

A mobile device doesn't always have to depend exclusively on GPS to estimate its location.

Other technologies can help.

The video mentions:

### 1\. Wi-Fi Location

Nearby Wi-Fi networks can be used to estimate where the device is.

This can be useful when GPS isn't available or doesn't have a good signal.

---

### 2\. Cellular Tower Triangulation

Cellular networks can estimate a device's location based on its relationship to multiple cellular towers.

The network can use signals from different towers to determine an approximate location.

---

# 35\. Location Technologies Comparison

| Technology | How it Determines Location | Example |
| --- | --- | --- |
| **GPS** | Uses satellite signals | Maps/navigation |
| **Wi-Fi** | Uses nearby Wi-Fi networks | Indoor/location estimation |
| **Cellular** | Uses multiple cellular towers | Approximate location |

### Important

If GPS isn't working properly, other technologies may still provide location information.

# Common Mistakes / Confusing Points ⚠️

### 1\. Cellular vs Wi-Fi

**Cellular:**

Phone → Cellular tower → Carrier network

**Wi-Fi:**

Phone → Access Point → Local network/Internet

---

### 2\. Hotspot vs Wi-Fi

Hotspot is **not a separate wireless technology like Wi-Fi**.

A phone can use:

**5G → Phone → Wi-Fi → Other devices**

The phone is acting as the Internet-sharing point.

---

### 3\. SIM vs Phone Number

The SIM is not simply "the phone number."

It contains identification and network-related information associated with the subscriber/service, including information associated with the phone number.

Moving a SIM can allow the service/number to be used on another compatible phone.

---

### 4\. Physical SIM vs eSIM

**Physical SIM:**

> Remove → Insert

**eSIM:**

> Software → Transfer/Activate

---

### 5\. Pairing vs Connecting

**Pairing = establish the relationship initially.**

**Connecting = establish communication using an already-paired relationship.**

---

### 6\. GPS vs Cellular Location

GPS:

> Satellites

Cellular location:

> Cellular towers

Wi-Fi location:

> Nearby Wi-Fi networks
